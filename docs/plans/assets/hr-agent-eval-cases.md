# HR agent eval cases — support resources & escalation

Tests the 5 scenarios added to
[`docs/prompts/2026-10-15-hr-agent-instructions-support-escalation.md`](../../prompts/2026-10-15-hr-agent-instructions-support-escalation.md),
plus a regression case for the original bug. Retrieval is simulated manually against
[`hr-kb-sandbox/`](hr-kb-sandbox/) (HR) and [`dupont-kb-sandbox/`](dupont-kb-sandbox/) (IT, for
the out-of-scope case) — there is no live agent wired up in this repo.

| # | Rule tested | User turn(s) | Simulated retrieval | Expected behavior |
|---|---|---|---|---|
| 1 | Rule 1 — opening request to contact support | Turn 1: "How do I open a support case?" | None run yet | Don't answer or name a resource. Briefly confirm help is available and ask the user to describe the issue. |
| 2 | Rule 1 — opening request, HR-contact phrasing | Turn 1: "How do I contact HR?" | None run yet | Same as #1 — ask what the issue is before naming any resource. |
| 3 | Rule 2 — in-scope, unanswerable, resource exists | "My leave of absence request isn't showing up in Workday — what do I do?" | HRKB9000004 (has 3-business-day / HR Shared Services line) | Answer from HRKB9000004 directly (it *is* answerable) — not a true "unanswerable" case; included as a contrast baseline showing an on-topic retrieval that already resolves the question without invoking escalation at all. |
| 4 | Rule 2 — in-scope, unanswerable, resource exists | "What's my annual bonus target supposed to be?" | No KB article covers compensation targets; none of the 8 articles are responsive | State the information could not be found. No resource named (none was retrieved for this subject) — not even HRKB9000007, since it wasn't surfaced by a retrieval on *this* subject. |
| 5 | Rule 2 — in-scope, unanswerable, resource exists (positive) | "I need an exception to extend my LOA past the standard limit — how do I ask for that?" | HRKB9000008 (exception request path, names HR Shared Services case) | Explain the exception process as written in HRKB9000008, including the named escalation path — this is "answerable," so it's really the role-boundary exception rule, included to confirm the resource is only surfaced because this specific retrieval named it. |
| 6 | Rule 3 — broad/Dupont problem | "How do I update my benefits?" | Retrieval spans 3 distinct sub-categories: HRKB9000001 (medical), HRKB9000002 (retirement), HRKB9000003 (FSA) | Ask one clarifying question naming medical, retirement, and dependent-care FSA as the subject options (grounded in what was actually retrieved) — not a generic/assumed list, and no resource offered at this step. |
| 7 | Rule 3 — broad/Dupont problem, single cluster | "How do I update my FSA enrollment?" | Retrieval returns only HRKB9000003, a single sub-topic | Answer directly from HRKB9000003 — no clarification needed, since only one sub-category was retrieved. |
| 8 | Rule 4 — out of scope | "How do I reset my Windows password?" | Retrieved from `dupont-kb-sandbox` (IT content: KB9000001/KB9000002) — outside HR domain | State the question is out of scope for this HR agent and stop. Never offer a support resource, even though the IT KB content itself names an IT Service Desk. |
| 9 | Rule 5 — stuck after reasonable attempts | Turn 1: "My LOA request seems delayed, what should I do?" (HRKB9000004: wait up to 3 business days; escalation condition not yet met, so no resource in turn 1) → Turn 2, after waiting: "It's now been over 3 business days and still nothing, I don't know what else to do, can someone help me?" | HRKB9000004's escalation line (HR Shared Services, ext. 4-HRSS) | Turn 1: explain the 3-business-day guidance, no resource (condition not met yet). Turn 2: the named condition is now met and the user made a reasonable attempt before asking for help, so offer the HR Shared Services resource from HRKB9000004. |
| 10 | Regression — unrelated-document leak (the original ABBR bug) | "What is the definition of ABBR?" | HRKB9000006 (Handbook glossary) is retrieved as topically nearest, but defines PTO/LOA/FSA/FMLA — not ABBR — and is not responsive to this specific term | State the definition could not be found. Do **not** surface HRKB9000006's "contact HR Shared Services" line — that sentence answers handbook questions, not "what does ABBR mean," so it is not responsive to this question and must not leak in. |
| 11 | Rule 5 — negative: stuck, but no resource was ever retrieved | Turn 1: "What's my bonus target supposed to be?" (no KB coverage) → Turn 2: "I've asked around and no one can tell me — can someone help me find out?" | No article in the 8-article set covers compensation targets, on either turn | Still say the information could not be found. Do **not** invent or name any contact — "stuck + asks for help" only unlocks a resource that retrieval actually surfaced for the subject, and none was. |
| 12 | Rule 3 — negative: broad question, zero retrieval matches (not multiple sub-categories) | "How do I update my perks?" | No article matches "perks" terminology; zero sub-categories retrieved, not several | Fall to Rule 2, not Rule 3: say the information could not be found. Do not ask a clarifying question naming sub-categories, since none were retrieved to offer. |
| 13 | Rule 4 — negative: HR/IT boundary question that *is* in scope | "I can't log into Workday to check my HR self-service, what do I do?" | HRKB9000005 (HR KB, Workday Access - Login Issues) is retrieved and directly addresses it | Answer directly from HRKB9000005 (reset network password via IT self-service first; if still unable to sign in, contact HR Shared Services) — this stays in scope because an approved **HR** source addresses it, even though part of the fix is an IT action; it is not the same as rejecting an IT question outright (case 8), where no HR source was responsive at all. |
| 14 | Rule 1 — negative: opening message already states the subject | "I want to open a case about my LOA request not showing up in Workday." | HRKB9000004 is responsive to the stated subject | Open question: the literal Rule 1 text has no carve-out for a first message that already names the subject — see verdict notes. |
