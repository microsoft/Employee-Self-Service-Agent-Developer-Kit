# Delete evaluations

Deployed evaluation-set deletion is not available through ADK. Explain the boundary and stop before changing local files.

Direct remote cleanup to the evaluation view for the confirmed agent in Copilot Studio. Do not equate removing a local case or creating a new copy with deleting the retained remote set.

For separately requested edits to evaluation cases, follow `src/skills/evaluations/update/SKILL.md`, preserving explicit case intent, quality review, and separately approved deployment. Native deployment may create a new copy while retaining the old remote set; disclose that outcome.
