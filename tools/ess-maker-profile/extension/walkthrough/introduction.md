# Welcome to the Agent Developer Kit!

Build, update, and publish your Employee Self-Service agent with plain English. No code required.

The workspace is organized into three areas:

- **Actions (left):** Quick actions, customization options, and help — everything you need to drive the build from one rail.
- **Preview (center):** Follow the steps here and keep your reference material in the same workspace as your agent.
- **Copilot chat (right):** Describe what you want your ESS agent to do. Copilot turns your intent into set-up steps, topics, and configuration.

Work top to bottom: during **Set up**, use the Microsoft work account that can access your target Power Platform environment and agent. This is separate from the GitHub Copilot sign-in that activates Copilot Chat. Then create or modify topics, run a flight check, and push your changes to Copilot Studio.
