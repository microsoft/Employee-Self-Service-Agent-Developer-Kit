# Connect

The **Connect** button opens `/setup`, which may ask you to sign in with the Microsoft work account that can access your target Power Platform environment and agent. This is separate from the GitHub Copilot sign-in that activates Copilot Chat.

- Discover your deployed ESS agent and its components.
- Create a local working copy for safe editing.
- Validate connectivity before any changes are pushed.

When you click Connect, a chat opens with the `/setup` command — just answer the prompts.

> First time? A separate browser window may ask you to select your Microsoft work account. Use the account that can access the target Power Platform environment and agent.
