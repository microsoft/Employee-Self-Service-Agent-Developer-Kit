# What the Agent Developer Kit does

The Agent Developer Kit helps you customize your Employee Self-Service agent through plain-English requests, reviewed drafts, and approved saves.

## How it works

Describe what you want in plain English and GitHub Copilot does the heavy
lifting. It turns your intent into the right set-up steps, topics, and
configuration, then helps you review and save supported changes:

- **Set up** — use your Microsoft work account to access the target Power
  Platform environment and connect your agent. This is separate from the GitHub
  Copilot sign-in that activates Copilot Chat.
- **Customize**: create and update conversation topics, tailor the landing page, and scan
  for issues.
- **Validate** — run a flightcheck and generate tests before you deploy.
- **Save**: approve selected topic, instruction, or evaluation changes and inspect the result.

Topics are saved to the selected editable Dev agent after you approve the proposed behavior. Creation leaves a topic inactive; updates preserve its identity and active state. Instruction changes require separate approval. Saving does not activate or publish, and conversation testing remains pending when the installed capability or topic readiness does not support it.

You don't need to know YAML, JSON, or any code — just tell Copilot what you
want.
