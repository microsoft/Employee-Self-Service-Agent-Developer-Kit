# What the Agent Developer Kit does

The Agent Developer Kit helps you build, update, and publish your Employee
Self-Service agent — the assistant your employees use for HR, IT, and
facilities requests — without writing any code.

## How it works

Describe what you want in plain English and GitHub Copilot does the heavy
lifting. It turns your intent into the right set-up steps, topics, and
configuration, then helps you validate and publish:

- **Set up** — sign in to your Power Platform environment and connect your agent.
- **Customize** — create and update topics, tailor the landing page, and scan
  for issues.
- **Validate** — run a flightcheck and generate tests before you deploy.
- **Publish** — push your changes to Copilot Studio.

You don't need to know YAML, JSON, or any code — just tell Copilot what you
want.
