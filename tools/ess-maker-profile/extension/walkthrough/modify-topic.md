# Modify a topic

Already have a topic and want to change how it behaves? When you click **Modify a topic**, a chat opens where you describe the change in plain English. The kit will:

- Read the selected topic's current saved content and its local draft.
- Draft the requested change while preserving unrelated behavior and existing integration contracts.
- Preview the topic change and any separately proposed instruction change for separate approvals.
- Save the approved topic update to the selected editable Dev agent and verify its content.

The topic keeps its identity and active state. A save does not activate, publish, or verify employee chat behavior. Power Automate authoring remains outside ADK.

### Examples

> "In the PTO topic, also show the employee's accrued sick leave, not just vacation days."

> "Change the IT ticket topic so it asks for the building and floor before filing the ticket."
